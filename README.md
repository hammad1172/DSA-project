# DSA-project

Flight Reservation System (DSA Project)
A console-based C++ application that simulates a flight seat booking system using core Data Structures and Algorithms.

🔑 Key Features
Book/cancel seats by number or passenger name
Search passengers and seat assignments
Display booked/available seats
Sort passengers by name
BST-based in-order seat display
Find max/min booked seat using BST

DSA Concepts Used
Binary Search Tree (BST) – for ordered seat management
Set – for available seat tracking
Vector & Sorting – for passenger listing

Tech Stack
Language: C++
Libraries: iostream, set, unordered_map, vector, algorithm
